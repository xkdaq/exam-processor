# 答案生成规范

## 名词解释答题规范

结构：定义 → 特征 → 分类/内容 → 例证 → 意义/影响

示例：
```
象征型文学是一种侧重以暗示的方式寄寓审美意蕴的文学形态。

（1）基本特征：
① 暗示性：通过暗示、象征表达意义；
② 朦胧性：意义含蓄，多义性强；
③ 超越性：追求对现实世界的超越。

（2）主要类型：
① 寓言式象征；
② 符号式象征；
③ 整体象征。

（3）代表作家作品：
波德莱尔《恶之花》、艾略特《荒原》、李商隐诗歌等。

（4）文学史意义：
象征主义是19世纪末重要的文学思潮，对现代主义文学产生了深远影响。
```

## 简答题答题规范

结构：总述 → 分点论述（①②③）→ 总结

要求：
- 分点清晰，每点有独立内容
- 适当举例说明
- 语言简洁，条理分明

示例：
```
民间文学对作家文学的影响主要体现在以下几个方面：

（1）题材方面：民间文学为作家文学提供丰富素材，如《西游记》《水浒传》都取材于民间故事。

（2）人物形象方面：民间文学中的人物成为作家创作素材，经过艺术加工赋予新意义。

（3）艺术手法方面：民间文学的叙事技巧、修辞手法被作家借鉴。

（4）语言方面：民间文学的口语化、生动性影响作家语言风格。

总之，民间文学是作家文学的"母体"，二者相互促进，共同发展。
```

## 论述题答题规范

结构：引言 → 论点1+论据+分析 → 论点2+论据+分析 → 论点3+论据+分析 → 总结

要求：
- 论点明确，论据充分
- 分析深入，逻辑严密
- 层次分明，结构完整
- 适当引用原文或理论

示例：
```
【引言】
宋江的"义气"是《水浒传》的核心主题之一，体现了儒家思想与江湖道义的复杂结合。

【分论点一】
（1）仗义疏财
情节：宋江"及时雨"之名传遍江湖，对落难好汉慷慨解囊。
分析：体现儒家"仁者爱人"的思想，是"义"的重要表现。

【分论点二】
（2）救困扶危
情节：私放晁盖、通风报信。
分析：虽触犯王法，但符合儒家"舍生取义"的精神。

【总结】
宋江的"义气"既有江湖道义的成分，更有儒家伦理的底色。
```

## 解析格式要求

1. **适当换行**：在标题、分点、段落之间添加换行
2. **使用标记**：【】标记小标题，（1）（2）标记分点
3. **保持专业**：使用学术语言，避免口语化
4. **控制长度**：根据题目分值决定解析详略

## 常见科目答题要点

### 文学类
- 结合作品具体分析
- 引用原文或评论
- 注意历史脉络和流派特征

### 语言学类
- 定义准确，举例恰当
- 注意古今对比
- 使用国际音标或专业符号

### 教育类
- 理论联系实际
- 结合教育政策和案例
- 体现教育理念和价值观

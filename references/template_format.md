# Excel模板格式规范

## 字段说明

| 字段名 | 必填 | 说明 |
|--------|------|------|
| ID | 是 | 序号，从1开始递增 |
| 题目 | 是 | 完整题目内容 |
| 题型 | 是 | 问答题/单选题/多选题 |
| 分数 | 否 | 题目分值，数字或空 |
| 难度 | 否 | 留空 |
| 选项A | 否 | 客观题填写 |
| 选项B | 否 | 客观题填写 |
| 选项C | 否 | 客观题填写 |
| 选项D | 否 | 客观题填写 |
| 选项E | 否 | 客观题填写 |
| 答案 | 否 | 客观题填答案，主观题留空 |
| 解析 | 是 | 完整答案/解析内容 |
| 一级目录 | 是 | 年份+学校+科目 |
| 二级目录 | 是 | 实际题型分类 |

## 一级目录命名规范

格式：`年份+学校+科目代码`

示例：
- 26年福建师范大学810
- 25年北师大901
- 24年北京师范大学808
- 2026年教育时政

## 二级目录分类

### 主观题
- 名词解释
- 简答题
- 论述题
- 综合题
- 分析题

### 客观题
- 单选题
- 多选题
- 判断题
